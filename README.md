# 📊 Sales Data Analytics Dashboard

An end-to-end data analytics project that ingests sales data into MySQL and visualizes insights using Streamlit.

## 🔹 Features
- MySQL-based data storage
- Interactive Streamlit dashboard
- Product & month filters
- Sales KPIs (Revenue, Orders, Quantity)
- Monthly sales trend
- Top-selling products

## 🛠 Tech Stack
- Python
- Pandas
- MySQL
- SQLAlchemy
- Streamlit

## 🧱 Project Architecture
CSV → Python ETL → MySQL → Streamlit Dashboard

## 🚀 How to Run
```bash
pip install -r requirements.txt
streamlit run streamlit_app/app.py
